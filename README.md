# DeBarrio

```bash
cd debarrio-mobile
npm install
npx expo start
```

DeBarrio es una aplicación para iOS y Android construida con Expo y Expo Router.
Configura las variables de Supabase en `debarrio-mobile/.env.local` antes de
iniciarla. Consulta [`debarrio-mobile/README.md`](./debarrio-mobile/README.md)
para los pasos de configuración y desarrollo.
